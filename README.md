

# 🐧 Tux Birthday Page

A simple single-file HTML tribute page celebrating Linux's 35th birthday.

## Features
- Black background with a glowing Tux emoji centerpiece
- "Happy 35th Birthday, Linux!" message
- Terminal-styled box showing live `uname -a` output from the build system

## Tech
- Pure HTML + CSS (no dependencies, no JS)
- Single file: `tux_birthday.html`

## Usage
1. Download `tux_birthday.html`
2. Open it in any browser
3. That's it — no build step, no server needed
